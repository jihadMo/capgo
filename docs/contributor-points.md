# MisakaNet Contributor Reputation Points System

The contributor reputation points system rewards high-quality lesson contributions and community growth **without cryptocurrency, blockchain, tokens, or financial promises**.

> **[IMPORTANT] Disclaimers & Legal Notice**
> - **No Cash / Monetary Value:** Reputation points are purely internal project recognition.
> - **Non-Transferable:** Points cannot be traded, transferred, sold, or exchanged.
> - **Not a Financial Asset:** Points are not tokens, cryptocurrencies, or investment instruments.

## Point Rules Matrix

| Action | Points | Description |
| :--- | :--- | :--- |
| **Lesson Merge** | +10 | Submitted a lesson that passed review |
| **Search Hit** | +1 / hit | Lesson selected in search results (deduped per 24h) |
| **Helpful Vote** | +3 / vote | User marked lesson as helpful (1 vote / user) |
| **E2+ Evidence Level** | +5 | Maintainer verified evidence rating |
| **Social Growth Bounty** | +15 | Verified social promotion task |

## Anti-Abuse Rules
- **Daily Cap:** Maximum 50 points per day per user.
- **New Account Throttle:** Accounts < 7 days old capped at 20 points/day.
- **Inactivity Freeze:** 12 months with no contributions freezes points without deduction.
